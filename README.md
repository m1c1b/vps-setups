# vps-setups

Готовые Docker Compose стеки для развёртывания на VPS

## Безопасность

**Обязательно меняйте стандартные порты** перед развёртыванием на публичном сервере. Порты по умолчанию известны сканерам и используются при атаках:

- Порт панели 3x-ui (`2053`) — сменить на произвольный `>1024`
- Порт подписок (`2096`) — сменить на произвольный `>1024`
- Стандартные учётные данные `admin/admin` — сменить сразу после первого входа
